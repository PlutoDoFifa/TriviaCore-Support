# TriviaCore Support

Welcome to the official support and issue tracker for TriviaCore.

This repository is used for reporting bugs, incorrect trivia questions,
feature suggestions, and documentation issues.

## Reporting an Issue

Please use the appropriate issue template when creating a new issue.

### 🐛 Bugs
Report unexpected plugin behavior, errors, or other technical problems.

### ❓ Incorrect Trivia Questions
Found an incorrect, outdated, misspelled, or ambiguous question?
Please report it so it can be reviewed.

### 💡 Feature Requests
Have an idea for TriviaCore? Suggestions are welcome.

### 📖 Documentation & Configuration
Report incorrect documentation or problems understanding configuration.

## Source Code

This repository does not contain the TriviaCore source code.
It exists solely for support and issue tracking.
